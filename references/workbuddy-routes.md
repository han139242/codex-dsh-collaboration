# WorkBuddy 模型回退

1. 每次任务先用默认 `--route cn-flash`。如果回复空白、被截断、格式错误导致无法读取，或核实后明显答非所问，再用 `--route global-flash` 发送同一目标、约束和材料。
2. 两条 DeepSeek 线路都无法给出可用结果时，选择账号已有访问权限的 Hy4 Preview。优先尝试 `--route cn-hy4`。如果国内 Hy4 不可用，可用 `--route global-hy4`。只用已登录的 WorkBuddy 账号和已有积分。四条路线均走 WorkBuddy 插件。
3. 模型意见与 Codex 不同、提出有证据的问题、或者本机验收失败，按原任务核实并处理。换模型用于取回可用的独立意见。账号或服务明确不可用时，跳过相应路线。每条可用路线最多尝试一次，全部不可用时由 Codex 继续，并如实说明缺少独立意见。

切换时保留原回复和日志。原步骤尚未生成正式报告，可以在同一运行目录用原参数改 `--route`。不同路线有独立的运行日志与桌面接续文件，最后报告记录实际供应商和模型。已保存正式报告但经核实仍需另一个模型重看时，另存运行记录并在小结链接原结果。不要通过切换模型绕过用户的材料共享范围。桌面导回时沿用交接记录指定的模型和线路。
